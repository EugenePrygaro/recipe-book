# 🍲 Книга рецептів

Спільна книга рецептів для телефона й комп’ютера. Відкривається за звичайним посиланням без акаунтів, Telegram або паролів. Усі відвідувачі працюють з одними рецептами, фото, оцінками, обраним, продуктами вдома та списком покупок. Відкриті сторінки підтягують зміни приблизно кожні 15 секунд.

## Увага: сайт відкритий для всіх

Автентифікації немає. Будь-хто, хто отримає адресу сайту, може переглядати, додавати, змінювати й видаляти рецепти, фото та інші дані. Посилання саме по собі не захищає доступ.

## Розгортання на Vercel

1. Завантажте проєкт у GitHub і імпортуйте репозиторій у Vercel.
2. У Vercel підключіть **Upstash Redis** для рецептів, оцінок і списків.
3. Підключіть **Vercel Blob** для фотографій.
4. Переконайтеся, що в налаштуваннях проєкту є `KV_REST_API_URL`, `KV_REST_API_TOKEN` і `BLOB_READ_WRITE_TOKEN`, потім зробіть Deploy.
5. Надішліть посилання сайту іншому користувачеві. Нові дані зберігаються у спільних сховищах Vercel.

Сайт складається зі статичного фронтенду та Vercel Functions. Дані й метадані фото зберігаються у Redis; оригінали та зменшені копії фото — у Vercel Blob. Старі локальні дані з `npm run local` не переносяться, бо існують лише в пам’яті процесу.

## Розробка локально

Потрібен Node.js 20 або новіший.

```bash
npm install
npm run local     # http://localhost:3000; Vite + React, Redis і Blob у пам’яті
npm run preview   # збірка dist/ і локальний preview
npm run build     # збірка в dist/
npm test          # тести
npm run check     # перевірка синтаксису
```

Відкрийте `http://localhost:3000` після запуску `npm run local`. Локальний сервер не вимагає входу; API працює на окремому локальному порту, а Vite передає до нього API-запити. Дані й фото зникають після зупинки процесу.

Фронтенд переходить на React поступово: React/Vite вже керують точкою входу та статусом завантаження, а решта інтерфейсу поки лишається на старих модулях, щоб не втратити наявні функції під час міграції.

## Сезонні теми

- **Зима:** 1 грудня — кінець лютого, темна синя палітра й легкий сніг.
- **Новий рік і Різдво:** 10 грудня — 14 січня, гірлянда, сніг і сніжна смужка на хвилі.
- **День закоханих:** 12–15 лютого, темна червона палітра, сердечка й троянди.
- **Весна:** березень — травень, темна сливова палітра й пелюстки сакури.
- **Осінь:** жовтень і листопад, темна тепла палітра й листя.
- **Літо:** червень — серпень, темна зелена палітра, сонце й листочки.

Кнопка **«Тест тем»** унизу сторінки циклічно вмикає оформлення, а потім повертає автоматичний режим. Для прямого перегляду також можна відкрити адресу з `?season=newyear`, `winter`, `valentine`, `autumn`, `spring`, `summer`, `easter` або `none`.

## Функції

- пошук, фільтри, сортування, перерахунок порцій, калорії й БЖУ;
- рулетка страв і список «давно не готували»;
- пошук страв за продуктами, які є вдома;
- спільні рецепти, оцінки, історія приготування, обране й покупки;
- додавання та редагування страв із фото;
- сезонні оформлення за календарем і кнопка перемикання тем для тестування;
- PWA, встановлення на головний екран та офлайн-перегляд останнього знімка.

## Структура

```
api/                      відкриті Vercel Functions для читання й зміни даних
lib/                      сховище, перевірка даних, HTTP-помічники
public/                   фронтенд: HTML, CSS, JavaScript, React entry, іконки й шрифти
vite.config.js            Vite/React dev server і production-збірка
scripts/local-server.js   локальний сервер з in-memory Redis і Blob
tests/                    тести серверної логіки
```

## API

Усі маршрути `/api/*` доступні без автентифікації. Вони дозволяють читати й змінювати спільні дані:

| Метод і шлях | Що робить |
|---|---|
| `GET /api/data` | завантажити рецепти, правки, фото, оцінки й історію |
| `POST /api/recipes` `{recipe}` | додати страву |
| `PUT /api/recipes?id=…` `{recipe}` | змінити страву |
| `DELETE /api/recipes?id=…` | видалити страву та її фото |
| `PUT /api/edits?id=b-…` `{edit}` | змінити вбудовану страву |
| `DELETE /api/edits?id=b-…` | скасувати правки вбудованої страви |
| `POST /api/photos?id=…` `{image, thumb}` | завантажити фото та зменшену копію |
| `DELETE /api/photos?id=…` | видалити фото |
| `POST` / `DELETE /api/cooked?id=…` | позначити приготування або скасувати останнє |
| `PUT /api/ratings?id=…` `{stars}` | змінити спільну оцінку; `0` — прибрати |
| `GET` / `PUT /api/personal` `{state}` | завантажити або зберегти спільні обране, продукти й покупки |

Фото в Vercel Blob мають публічні URL. Не зберігайте там приватні зображення.

## Часті зміни

- **Додати вбудовану страву:** `RECIPES` у `public/js/data/builtin.js`.
- **Додати іконку:** `scripts/build-assets.mjs`, потім `npm run assets`; список іконок форми — `public/js/config.js`.
- **Змінити кольори чи стилі:** файли в `public/css/`.
- **Святкове оформлення:** `public/js/lib/season.js` і `public/js/ui/season.js`.
- **Змінити правила визначення продуктів:** `public/js/lib/products.js`.
